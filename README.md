# 🖼️ Art Gallery Website

A responsive art gallery website built to match the provided design as closely as possible. Users can explore the gallery, interact with elements, and view a map with a custom location pin.

## ✨ Technologies
- **HTML5** - Semantic markup structure
- **CSS3 / SCSS** - Styling with preprocessor for better organization
- **JavaScript** - Interactive functionality
- **Leaflet JS** - Interactive map implementation

## Features
- Fully responsive layout optimized for desktop, tablet, and mobile screens
- Hover states for all interactive elements (buttons, links)
- Interactive location map implemented using Leaflet JS with a custom location pin

## 🧩 The Process

I started by organizing the project structure, creating an assets folder and moving all provided files—such as icons, images, and fonts—into it. I then installed Sass as a development dependency to practice a component-based workflow.

Next, I defined custom design tokens (colors, spacing, typography) to closely match the Figma design. After carefully studying the layouts, I divided the project into three main structural components shared across both pages: header, main, and footer.

### Workflow
1. Structure each section using semantic HTML
2. Apply BEM naming conventions for clarity and scalability
3. Style components incrementally, matching the design as closely as possible
4. Implement responsive breakpoints and test layouts across screen sizes
5. Work on one component at a time, refining before moving to the next

## 📚 What I Learned
During this project, I strengthened both my technical skills and my approach to problem-solving:
- Improved my ability to break down a project into reusable components, reducing code duplication
- Practiced responsive image optimization using the <picture> element with multiple sources per breakpoint
- Gained confidence working with micro- and macro-layouts using CSS Grid
- Learned how to integrate Leaflet JS, add a custom marker, and explored styling Leaflet’s default UI to better integrate it with the design
-- Maintained clean Git history using conventional commit messages for better project organization

## ✨ Reflections
Each part of this project helped me better understand how to structure frontend applications, manage complexity, and improve user experience. It was more than just recreating a design, it was about solving real problems, learning new tools, and strengthening skills I’ll carry into future projects.
